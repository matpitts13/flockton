# Flockton

Free, open-source Windows apps for small online sellers (TikTok Shop, Etsy, eBay). Each tool does one packing-table job and runs entirely on your own computer.

**Website:** https://flock-ton.ravenburst.com

| Tool | What it does | Status |
| --- | --- | --- |
| [Pigeonslip](https://github.com/matpitts13/pigeonslip) | Shipping labels at 4 × 6 in, two to a letter page | Released |
| Robin | Thank-you stickers and package inserts | In progress |
| Weaverbird | Packing slips and invoices from order exports | Planned |
| Magpie | SKU and barcode labels | Planned |
| Egret | Product-photo cleanup | Planned |
| Nuthatch | Seller expense and receipt tracker | Planned |
| Kiwi | Ingredient labels | Planned |

This repo holds the Flockton website (`site/`). Deploy with `npx wrangler@4.160.0 deploy`.
